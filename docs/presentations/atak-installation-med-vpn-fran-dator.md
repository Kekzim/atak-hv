## 34.   Starta ATAK
- Tillåt alla frågor som kommer upp
- Tak Device Setup – Done
- Disable battery…. – OK
- Tillåt appen att köras i bakgrunden – Tillåt
- Avvakta ca 5-7 sek – Load Iconset blixtrar förbi på displayen
- Menyn i överkan fylls på med 3 ikoner

- Stäng ner ATAK – ”Hamburgaren” – Quit – Yes

- STARTA ATAK
- Klicka på ”Hamburgaren”, välj - Import
- Local SD - Klicka ikonen till vänster under S i Select Files to Import - Scrolla till Download
- Välj xxxxxx.zip (bock i rutan ute till höger) – OK
- Copy
- Logga in – user: Enligt lista , Pwd: Enligt lista (MRV-säk- inloggning-tak)
- OK – Tak server registration completed – OK
