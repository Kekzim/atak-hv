## Streaming: Setup TAK ICU för TAK telefon
- Öppna Appen ICU TAK (egen app)
- Under ”Hamburgaren” – Klicka på Kugghjulet – Broadcast Pref…
- Select Delivery Method – RTSP
- Broadcast Alias – Din Anropssignal enlig FAL-A
- Scrolla ner
- RTSP Server Address – xxx.xxx.xxx.xxxx:8554/”callsign”?tcp
- Scrolla ner
- Wowza Server Username – Tilldelat från Ansvarig
- Wowza Server Password – Tilldelat från Ansvarig
- Backa 1 steg
- Starta stream genom att klicka - röda pricken till höger
- Nere till vänster skall det blinka Broadcasting Video i grönt
- Stäng av stream – klicka på blå fyrkant ute till höger

## Setup i ATAK appen:
- Öppna ATAK
- Under ”Hamburgaren” – Video
- Klicka på +
- Type – RTSP
- Xxxx.xxxx.xxxx.xxxx:8554/callsign?tcp
- Alias Name : Callsign
- Wowza Server Username – Tilldelat från Ansvarig
- Wowza Server Password – Tilldelat från Ansvarig
- Add
- Klicka på ”Hamburgaren” till höger om din tillagda Videostream
- Send till de som behöver den via chat eller FEED
