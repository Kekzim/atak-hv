## Uppstart av ATAK enhet efter återställd ATAK:
- Starta ATAK
- Godkänn alla fönster
- ATAK laddar – TAK Device Setup – Done
- Avvakta till listen överst utökats med 3 ikoner
- ”hamburgaren” – skrolla till QUIT – YES
- Starta ATAK
- Klicka på ”Hamburgaren”, välj - Import
- Local SD - Klicka ikonen till vänster under S i Select Files to Import - Scrolla till Download
- Välj xxxxxxx.zip (bock i rutan ute till höger) – OK
- Copy
- Logga in – user: Enligt lista , Pwd: Enligt lista
- OK – Tak server registration completed – OK

Ange rätt Callsign och färg på ditt Team:
- Hamburgaren
- Settings
- Callsign and Device Preferences
- Callsign Preferences – My Callsign – Ange ditt Callsign enligt FAL-A – OK
- My Team – Välj färg efter ”färgsättning”
- Ange Remarks: #xxxxxxx (vid behov)
- Backa pil bakåt tills du har ren kartbild
- Klicka på kartikonen i överkant – välj din karta
- Backa tillbaka till ren kartbild
